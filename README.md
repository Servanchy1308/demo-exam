# Варианты Модуля 1 · ДЭ 09.02.06

Генератор решаемых тренировочных вариантов Модуля 1 «Сетевое и системное администрирование».

- **index.html** — страница студента: задание по коду варианта (например `X-12`), таймер на 1 час, копирование в Word, скачивание .docx, печать.
- **solve.html** — решение по тексту: вставьте задание (с этого сайта, официальный текст ДЭ или просто код варианта), страница найдёт параметры, подсветит то, чего нет в тексте, и выдаст скрипты по машинам, команды по пунктам, проверку и текст отчёта.
- **teacher.html** — страница преподавателя: задание, ключ с баллами, текст для отчёта, скрипты решения для Astra Linux CE и Альт, скрипты автопроверки, решение вручную, журнал группы, пакет вариантов.

Ссылка на конкретный вариант: `index.html#X-12`.

Ссылка группы (`index.html#g.X.abc234`) создаётся в разделе «Группа». Студент вводит фамилию и имя и получает личный вариант. Вариант вычисляется из ФИ, поэтому у преподавателя по тому же ФИ получается тот же вариант.

## Сборка

Исходники лежат в `src/`: общий код `shared.js` (в том числе таймер), логика преподавателя `teacher.logic.js`, интерфейс `teacher.ui.js`, страница студента `student.js`, страница решения по тексту `solve.js`. После правок пересоберите страницы:

```
cd src
python3 build.py pages
```

На GitHub Pages журнал группы хранится только в браузере преподавателя.

Тема оформления (светлая, тёмная или как в системе) переключается в правом верхнем углу.

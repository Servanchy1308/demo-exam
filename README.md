# Варианты Модуля 1 · ДЭ 09.02.06

Генератор решаемых тренировочных вариантов Модуля 1 «Сетевое и системное администрирование».

- **index.html** — страница студента: задание по коду варианта (например `X-12`), копирование в Word, скачивание .docx, печать.
- **teacher.html** — страница преподавателя: задание, ключ с баллами, текст для отчёта, скрипты решения для Astra Linux CE и Альт, скрипты автопроверки, решение вручную, журнал группы, пакет вариантов.

Ссылка на конкретный вариант: `index.html#X-12`.

## Сборка

Исходники лежат в `src/`. После правок пересоберите страницы:

```
cd src
python3 build.py pages
```

На GitHub Pages журнал группы хранится только в браузере преподавателя.
